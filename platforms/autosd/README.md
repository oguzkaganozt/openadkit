# AutoSD

Run an Open AD Kit deployment on AutoSD: `quadlet.py` turns `openadkit config`
into Quadlet units, the files they mount, and an Automotive Image Builder manifest.

Build and run instructions are in the [AutoSD documentation](https://autowarefoundation.github.io/openadkit/platforms/autosd/),
and the supported boards in [Supported Platforms](https://autowarefoundation.github.io/openadkit/platforms/#boards).
