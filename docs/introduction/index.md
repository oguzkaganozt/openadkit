# Introduction

**Open AD Kit** is a modular, container-based distribution of [Autoware](https://github.com/autowarefoundation/autoware) for building autonomous driving systems — from development laptops to vehicle edge deployment.

This section orients you before you dive in. Read the [Overview](overview.md) for *what* Open AD Kit is and *why* it exists, then follow the path that fits your goal.
